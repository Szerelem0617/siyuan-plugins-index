# 目录插件

启用插件后，会在顶栏右侧生成一个插件图标

左键点击插件图标，在当前文档下插入目录列表

右键点击插件图标，显示更多操作

`CTRL + ALT + I` 插入目录 

`CTRL + ALT + O` 插入当前文档大纲

# 1.9.1 版本更新

- **Supertag 功能**: 加入了类似 Tana 的 Supertag 功能，支持通过 Tag 快速对齐数据库属性。
- **属性继承**: 支持配置属性继承规则，方便对层级数据进行批量管理与填充。
- **构建器优化**: 优化了 Builder 的自动同步逻辑，完全尊重数据库中设置的图标、题头图及模板信息。

# 1.9.0 版本更新

- **数据库功能（测试）**: 加入了根据列表块创建数据库的功能。
- **快速触发**: `Alt + 点击` 数据库块或标题行，可以快速触发数据库同步功能。
- **模板增强**: 构建器支持根据数据库中的 `icon`、`title-img`、`template` 列信息，以特定模板批量创建文档。
