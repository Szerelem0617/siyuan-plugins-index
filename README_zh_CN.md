# 目录插件

启用插件后，会在顶栏右侧生成一个插件图标

左键点击插件图标，在当前文档下插入目录列表

右键点击插件图标，显示更多操作

`CTRL + ALT + I` 插入目录 

`CTRL + ALT + O` 插入当前文档大纲

# 1.9.1 版本更新

- **同步安全增强**: 修复了子块移动导致数据库条目消失的 Bug。
- **配置优化**: 仅由于创建数据库时才重置辅助列（Level/Path）的隐藏状态，保护用户的手动配置。
- **批量数据管理**: 增强了数据库对列表项的识别，支持更稳定的批量模板生成。

# 1.9.0 版本更新

- **数据库功能（测试）**: 加入了根据列表块创建数据库的功能。
- **快速触发**: `Alt + 点击` 数据库块或标题行，可以快速触发数据库同步功能。
- **模板增强**: 构建器支持根据数据库中的 `icon`、`title-img`、`template` 列信息，以特定模板批量创建文档。
