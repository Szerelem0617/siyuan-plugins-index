# IndexOS v1.10.0 版本更新与测试验收清单 (Milestone Checklist)

为了保证 IndexOS（目录与命令/数据库管理插件）在 v1.10.0 版本的质量与稳定性，特别是其核心的 **命令管理**、**SQL 操作 AV 数据** 以及 **类管理（层级运行流）**，整理了本里程碑目标与验收测试 checklist。

---

## 一、 核心发布功能 (Release Scope)

### 1. 命令管理 (Command Management)
*   **定位**：将思源内置与第三方插件的操作逻辑数据化。支持通过统一的全局桥梁进行命令注册、分类管理与调用。
*   **中转站架构**：其它插件可通过 `window.indexOS.commands` 注册、销毁和触发命令。
*   **Scope**：明确命令的执行范围（Block 级别还是 Page 级别）。

### 2. SQL 操作 AV 数据 (SQL on AV Data)
*   **定位**：通过标准 SQL DDL/DML 操作思源的属性视图（Attribute View）数据。
*   **写入控制**：在 SQLite 层面模拟事务写入控制，通过思源原生的 `/api/transactions` 将改动广播写回 AV 配置文件，并拒绝只读列的非法写入。
*   **View 视图创建**：支持 SQL `CREATE VIEW` 语句在指定表上创建 Table、Kanban、Gallery 视图，并自动进行前端 Block 重绘刷新。

### 3. 类与层级管理 (Class Management & Type Binding)
*   **定位**：通过 Layer 3 (Type-DB) 将命令绑定到具体的 Supertag（类）上。
*   **参数延迟绑定流**：
    *   **无 Layer 4 数据库时**：自动向执行器传递“当前触发块”自身的物理参数。
    *   **有 Layer 4 属性数据库时**：根据接线关系，从 Layer 4 提取实例数值，作为上下文参数执行。

## 二、 v1.10.0 详细验收清单 (Checklist)

### 🗂️ 1. 命令中转站与全局 API 暴露
- [ ] **全局 API 挂载**：在 `window.indexOS.commands` 挂载以下标准接口，供第三方调用：
  - `registerCommand(def: CommandDef): void`（带规范命名校验，必须以 `plugin.[pluginName].` 开头）
  - `unregisterPlugin(pluginName: string): void`
  - `getCommand(id: string): CommandDef | undefined`
  - `executeCommand(id: string, params?: any, context?: any): Promise<DispatchResult>`
- [ ] **生命周期测试**：编写一个测试 Mock 插件，在 `onload` 中向 `window.indexOS.commands` 注册测试命令；在 `onunload` 时调用 `unregisterPlugin`，验证命令从命令面板及面板中同步移除。

- [ ] **层级绑定快捷键映射（Layer 2 Global Binding）**：
  - 允许在 AV 界面配置全局命令绑定（快捷键与 Alias 别名）。
  - 自定义定义的别名可以在思源的 `/` 斜杠命令菜单中检索到并正常触发。

### 🛢️ 2. SQL 引擎、增量同步与非法写入校验
- [ ] **`CREATE VIEW` 视图创建测试**：
  - [ ] 验证 `CREATE VIEW "My Table" AS SELECT * FROM "Tasks"`（创建默认表格视图）。
  - [ ] 验证 `CREATE KANBAN VIEW "My Kanban" AS SELECT * FROM "Tasks"`（创建看板视图并自动选择分组列）。
  - [ ] 验证 `CREATE GALLERY VIEW "My Cards" AS SELECT * FROM "Tasks"`（创建卡片视图）。
  - [ ] **唯一块校验**：当文档中无对应 AV 块时，或存在 2 个以上镜像 AV 块时，执行创建视图应抛出友好错误提示，限制仅在“唯一块”下执行事务。
  - [ ] **前端自动重绘**：视图创建后触发 `triggerAvBlockRender` 强刷，页面上的 Tab 栏自动显示新视图。
- [ ] **DML 字段写入校验 (Type Safety)**：
  - [ ] 测试向 `number` 类型字段写入非数字字符，验证其被拦截并回滚。
  - [ ] 测试向 `checkbox` 类型字段写入非 boolean/0/1 的无效数据。
  - [ ] 测试对 `created`、`updated`、`rollup`、`block` 等只读字段执行 UPDATE，验证报错拦截。
- [ ] **增量同步 (Incremental Sync)**：
  - [ ] 在 Siyuan 自带的属性视图中修改某一单元格内容。
  - [ ] 在 1.5 秒防抖时间后，在 SQL 控制台执行 SELECT 查询该行，验证 SQLite 数据库中的值已自动保持最新（变更指纹 `_computeDataHash` 能捕获单元格值的微小修改）。

### ⚙️ 3. 带参数命令执行与层级流测试
- [ ] **Copy Command Link 功能**：
  - 在 Layer 2 配置界面中，点击“复制命令链接”，能成功获取 `siyuan-btn://` 执行链接。
  - 粘贴后点击，可直接触发对应块的命令。
- [ ] **参数传递逻辑链条测试**：
  - [ ] **场景 A (无 Layer 4)**：将带有入参的命令绑定至普通块类型上。触发时，Dispatcher 应通过 IAL 获取当前触发块 the IAL 属性并自动填充给命令。
  - [ ] **场景 B (有 Layer 4)**：将命令绑定至已挂载了 Layer 4 数据表的 Supertag。修改 Layer 4 对应单元格的值，触发命令，验证执行器接收到了 Layer 4 的最新数值作为实参，取得不同的执行效果。
- [ ] **别名映射测试**：在思源斜杠命令菜单中输入注册的别名，回车后正常唤起快捷交互或执行。

### 🏷️ 4. 超级标签 (Supertag) 列表项与幂等性验收
- [ ] **列表项嵌套隔离（解决重复添加父列表 Bug）**：
  - 在列表项（Task）中打上 Supertag。
  - 在列表下敲击回车新建其他列表项，或者勾选/取消勾选 Task 复选框。
  - 验证：只会同步当前的列表项至数据库，**父列表块（NodeList）不会被作为单独的行重复插入**到数据库中。
