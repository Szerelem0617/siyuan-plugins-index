# 教学插件 (Teaching Plugin) 架构与头脑风暴

> 基于现有 Python 桌面程序 `physdb_python` 的功能分析，结合思源笔记生态与 IndexOS ECS 架构，设计下一代教学辅助插件。

---

## 一、现有 Python 项目功能拆解

### 1.1 备课程序 (main.py) — 课前

| 功能模块 | 实现方式 | 核心数据 |
|:---|:---|:---|
| **题库搜索** | SQLite 全文搜索 MCQ/SQ，支持关键词+号连接、级别过滤 | `physdb.db` (8.8MB) |
| **收藏树管理** | JSON 树结构：`Lessons → Module → Lesson → Topic → Segment`；`Students → Class → Student` | `favorites.json` (933KB) |
| **图片/视频收藏** | 拖拽/粘贴上传到分支 + 双份存储 (本地+widget) | `uploaded_images/`, `uploaded_videos/` |
| **文字笔记** | 纯文本笔记，按 NOTE_ID 分割存储在 `all_notes.txt` | `notes/all_notes.txt` |
| **Richtext 注释** | 每个收藏项可附加富文本注释 | `notes/all_richtext.txt` |
| **标签系统** | 对 segment 层级的收藏打标（evo_formation 等进化标签） | 内嵌在 favorites.json |

### 1.2 上课程序 (widget_main.py) — 课中

| 功能模块 | 实现方式 | 说明 |
|:---|:---|:---|
| **悬浮窗** | `Qt.WindowStaysOnTopHint` + 半透明背景 | 始终在最前，不遮挡主屏 |
| **段落导航** | 按 Topic/Segment 列表过滤 + 键盘上下翻页 | 按 essential/optional/ignored 优先级过滤 |
| **图片预览** | hover 预览按钮触发，支持滚动大图 | 复制后自动跳转下一未复制项 |
| **文字预览** | hover 笔记按钮触发 | 同样支持复制+自动推进 |
| **快捷键评分** | a/b/c/d/e 快速记录学生表现到 Excel | 简写字典展开为完整评语 |
| **反馈录入** | 选中学生 → 快捷键 → 写入 Excel 对应行列 | 按知识点列+学生行定位 |

### 1.3 自动反馈 (autofeedback/) — 课后

| 功能模块 | 实现方式 | 说明 |
|:---|:---|:---|
| **通用反馈生成** | DeepSeek API 生成知识点总结+课堂内容概要 | 基于知识树 + 课堂记录 |
| **学生个性反馈** | DeepSeek API 为每个学生生成个性化课堂表现评语 | 140-160字，含学术英文 |
| **Excel 模板** | openpyxl 读写 xlsx 模板文件 | 按行列定位写入反馈 |
| **知识树参考** | 硬编码物理/生物 IG/AL 知识树 | 用于 LLM 上下文参考 |

## 二、迁移到思源插件的架构映射

### 2.1 核心思路：笔记即数据库

Python 版的痛点：
- `favorites.json` 是私有格式，不可搜索、不可跨应用
- 图片是文件系统副本，与笔记内容割裂
- 知识树硬编码在代码里，不能动态编辑
- Excel 反馈文件是独立产物，不与知识体系关联

**思源版的优势**：
- 知识树 = 文档树/大纲，天然可编辑
- 题目/图片 = 思源块，可引用、可搜索、可双链
- 收藏分支 = 属性视图 (AV) 数据库行
- 学生记录 = AV 数据库行，与知识点列交叉
- 反馈 = 文档块，可追溯、可版本控制

### 2.2 数据模型映射表

| Python 概念 | 思源映射 | 存储方式 |
|:---|:---|:---|
| `Lessons` 树 | 课程笔记本/文档树 (大纲) | 思源原生层级 |
| `favorites` 关联 | **块自定义属性** (QuestionIDs) | **Heading 属性锚点** |
| 真题/图片 | 冷数据题库 (只读) | 插件外挂 SQL |
| 学生数据 | 学生 AV 数据库 | Attribute View |
| 课堂反馈 | 课堂记录 AV | AV + 关联块 |

### 2.3 与 IndexOS 四层架构的集成

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: 教学命令注册                                        │
│  teach.search / teach.startLesson /                          │
│  teach.grade / teach.generateFeedback                       │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 命令变体 (Command-DB)                               │

├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤

│  Student-DB: {name, class, linked_module, performance}      │
│  Resource-DB: {block_ref, type, label, priority}            │
│  Session-DB: {date, class, topic, records[]}                │
└─────────────────────────────────────────────────────────────┘
```

## 三、核心功能规划（已有 + 新增）

### 3.1 已有功能迁移（6 个）

#### F1: 备课资源匹配 (冷热分离)

- **知识树**: 维持思源原生文档树，利用 `#KP` 类标记关键大纲。
- **冷搜索**: 搜索 1000+ 静态真题由插件外挂 SQL 处理，不污染思源全局索引。
- **关联**: 通过 `QuestionID` 建立教案段落与真题图片的引用，而非创建物理块。
- **优势**: 保护真题数据不被误删，且保证思源加载大规模图片题库不卡顿。

**价值**: ★★★★★ — 开发基础，解决大规模图片存储难题。

#### F2: 独立教学窗口 (Standalone Widget)
- **实现**: 模仿 Python 悬浮窗，通过 `window.open` 弹出**独立 OS 窗口**。
- **解耦**: 窗口独立加载轻量 HTML/CSS，不携带思源编辑器臃肿类库。
- **功能**: 支持窗口置顶 (`staysOnTop`)、全屏展示、画中画，完美解决焦点冲突。
- **渲染**: 弃用 Protyle 嵌入，改用 API 获取块 Markdown 并通过 Lute 静态渲染。

**价值**: ★★★★★ — 彻底解决快捷键冲突，复刻 Python 级流畅体验。

#### F3: 学生管理 (1对1 专注)
- **实现**: 课程启动时自动关联唯一学生，评分操作默认归属于该上下文，保持架构可扩展。

#### F4: 快捷评分与记录
- **实现**: 评分面板写入 Session-DB (AV)，支持快捷键 (a-e) 与简写字典自动展开。

#### F5: 语音转文字 (STT)
- **实现**: Web Speech API 实现短语音识别，转录内容自动作为评语追加到 AV 单元格。

#### F6: LLM 反馈生成
- **实现**: 根据课堂时间线与评分记录，调用 LLM 一键生成知识点总结与个性化评语。

---

#### F7: 掌握度热力图 (Heatmap)
- **概念**: 可视化 `学生 × 知识点` 的正确率矩阵。
- **价值**: 直观识别全班薄弱点，为个性化复习提供数据支持。
- **实现**: 基于 Session 记录进行 SQL 聚合生成 SVG 矩阵图。

#### F8: 课堂时间线与回顾 (Timeline)
- **概念**: 自动记录课堂事件流（何时换题、何时点名、点名表现）。
- **价值**: 捕捉课堂节奏，为 LLM 生成反馈提供包含“过程”的上下文。
- **实现**: 事件采集器静默记录操作日志，课后生成可视时间轴。

### 5.2 数据库 Schema 设计

#### Student-DB (学生数据库 AV)

| 列名 | 类型 | 说明 |
|:---|:---|:---|
| **学生名** | block (主键) | 学生块（可包含头像、个人信息） |
| **班级** | select | 所属班级 |
| **关联课程** | relation → Module 文档 | 对应 Lessons 树的 Module |
| **总课时** | rollup | 自动统计参与课时数 |
| **平均掌握度** | number | 由系统计算 |
| **最近出勤** | date | 上次上课时间 |

#### Session-DB (课堂记录 AV)

| 列名 | 类型 | 说明 |
|:---|:---|:---|
| **课堂ID** | block (主键) | 每次上课自动创建的课堂记录块 |
| **日期** | date | 上课日期 |
| **班级** | select | 上课班级 |
| **课程** | relation → Lesson 文档 | 对应哪节课 |
| **时长** | number | 课堂时长(分钟) |
| **知识点覆盖** | mSelect | 本次覆盖的知识点列表 |
| **状态** | select | 进行中/已完成/已生成反馈 |

#### Question-DB (冷数据 SQL - 只读资源)
- **QuestionID**: 主键 (如 2024-CIE-P1-Q15)
- **ContentPath**: 图片本地物理路径
- **Answer**: 答案文本
- **OCRText**: 辅助搜索的文本内容

#### Grade-DB (评分记录 AV)
- **记录ID**: 评分记录块
- **所属课堂**: Session-DB 关联
- **学生**: Student-DB 关联
- **知识点**: Segment 文档关联
- **评分**: a/b/c/d/e
- **关联题目**: **QuestionID (关联外挂 SQL)**
- **时间戳**: date

### 5.3 迁移方案 (favorites.json 拆解)
- **结构化映射**: `Branch/Lesson/Segment` -> `文档/文件夹/标题`。利用思源文档树作为“热数据”备课界面。
- **题目解耦**: Segment 下的题目列表存入对应标题块的 `custom-teaching-qids` 属性，不生成实体块引用。
- **教学触发**: 教学面板监控光标位置，若当前块含有 QID 属性，则自动从 SQL 冷库拉取图片展示。
- **学生数据**: 拍平 JSON 中的学生树，全量导入 Student-DB AV 记录。

## 六、开发 Milestone 与技术难点

### Phase 0: 数据基础 (W1-2)
- **迁移规划**: 解析 `favorites.json` 生成思源文档树大纲，并注入 QIDs 块属性。
- **冷库适配**: 配置外部 SQL 连接，支持根据 QuestionID 快速索引图片路径。
- **Schema**: 初始化 Student/Session/Grade AV 数据库。

### Phase 1: MVP 上课流程 (W3-5)
- 实现教学面板 (Dock) 与段落导航逻辑。
- 集成 Protyle 嵌入渲染。
- MVP 评分流程与基础快捷键拦截。

### Phase 2: 统计与反馈 (W6-8)
- 自动采集课堂时间线 (F8)。
- 对接 LLM 生成课后反馈 (F6) 并支持 Excel 导出。

### Phase 3: 优化与高级 (W9-12)
- 实现掌握度热力图 (F7)。
- 语音转文字集成 (F5)。

## 七、总体技术风险评估

| 风险 | 等级 | 缓解方案 |
|:---|:---|:---|
| Protyle 嵌入风险 | 🟢 低 | **已弃用**。改用 API 驱动的静态 HTML 渲染。 |
| 快捷键焦点冲突 | 🟢 低 | **方案 B 解决**。独立窗口拥有独立焦点，不干扰主编辑器。 |
| AV 数据实时同步 | 🟡 中 | 复用 IndexOS 已有的事件监听 + 异步 API 回传。 |
| 跨窗口通信延迟 | 🟡 中 | 使用 `Window.postMessage` 或桥接 API 确保秒级同步。 |
| 语音识别准确度 | 🟡 中 | 提供手动修正 UI + Whisper 备选方案。 |

## 八、与 Python 版的差异对比

| 维度 | Python 版 | 思源插件版 |
|:---|:---|:---|
| 数据持久性 | JSON/Excel | 思源 AV + 外部 SQL |
| 知识树 | 代码内硬编码 | 思源原生文档树 (可编辑) |
| **题目管理** | **独立 SQLite + 图片** | **独立冷数据 SQL + 图片 (通过 ID 握手)** |
| 课堂记录 | Excel 单文件 | AV 数据库 + 时间线 |
| 生态集成 | 孤立应用 | 与思源文档/反链/索引深度集成 |
